02 / 28

The firm

Turning organizations into AI entities. Not implementing advanced AI agents. A stored file is searched. A passage is copied. A second check confirms. If there is no passage, the turn stops. A named person signs anything that leaves.

A better model can be swapped. The sequence stays. That sequence is the kernel. The firm is the parent that sequence sits under, plus the people who sit on it, plus the scopes they take. Overlay on work that already exists. Ground-up when it does not. Same loop for a company, a public body, a nonprofit, a research group, or a cause.

Frontier, not overstated

This is how frontier corporate AI actually runs: named files, extract-only-stored, solver is not verifier, cite or refuse, fail closed. It is not a chatbot seat. It is not a live book in every type yet.

Kernel

The shared loop. Retrieve a passage from a hashed corpus, or stop. Extract only what is stored. Synthesize. Independent check — the solver is not the verifier. Cite, or refuse. Fail closed. A human name on done. See the kernel document.

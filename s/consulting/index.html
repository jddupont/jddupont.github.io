Consulting

Similar scope work for organizations of all types. A company, a public body, a nonprofit, a research group, a cause. Same loop. Named work, named files, named signer. Per scope.

Name the work first. Design the jobs as retrieve, extract, check, send. Choose files so a claim can be cited. Name who signs before anything leaves. If the work already exists, sit the same loop on it. Next workstream is the next loop, not a new platform. This is the intended path. Method proven. Not a live book in each type.

How it is built

Three scales. A programme is work in the world. A project is one job with one corpus and one signer. An organization is the set of jobs it will run. Agents support the first pass at every scale.

The loop

Retrieve, extract, synthesize, independently check, then cite or refuse. If there is no passage, there is no claim. A better model can be swapped without standing the work up again.

What is proven

The loop is proven on synthetic test files: thin retrieval refuses, a planted unsupported claim is caught. That is proof of the method, not proof of a named programme. Each stand-up still has to name its work and files.

12 / 16

Corpus

Ground-up, the files of record are chosen so they can be cited from day one. Overlay, we pull from systems already in use. Either way the teams retrieve a span. They do not remember it. If a needed fact has no stored passage, the turn stops.

Authority

Two modes, set when the work is stood up, before the first turn. A person reviews, then send, edit, or hold. Or it completes unless a flag fires. Building from the ground up does not widen anyone’s authority.

14 / 16

Done when

Value is whether a named programme, project, or job can run with a cited draft or a stop waiting, and a named person on anything sent.

Done when

  • The work is named. Jobs are designed as the loop, or taken from a workflow already in use.
  • Files of record are citable. A turn with no matching passage refuses.
  • Signers are named before the first output. Standing a team does not widen them.
  • A person can read the draft or the refuse. They still send.
  • The next workstream can be stood up the same way, on the same spine.

Not claimed

  • A lab of our own.
  • A model of our own. Models are swappable.
  • Agents run the company. They do not.
  • Headcount removed. We do not print that.
  • A live book of every organization type. This is the intended path.
  • A shipped consulting runtime. The method is proven. The SOW is not.
15 / 16

Refuse

If the file is not there, the work says so. It does not guess. A person can read the draft or the stop. That is what makes a programme, a project, or an organization built this way defensible.
